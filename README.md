# Library-collection-client

Frontend client for a Warhammer 40k library collection management system. Built with React 19, TypeScript, Vite, TanStack Router, and Tailwind CSS v4.

## Features

- Collection browsing and management
- React 19 with the React Compiler for optimized rendering
- File-based routing via TanStack Router
- Tailwind CSS v4 for styling
- ESLint + Prettier for code quality

## Prerequisites

- Node.js 18+
- npm or pnpm

## Setup

### Install dependencies

```sh
npm install
```

or with pnpm:

```sh
pnpm install
```

### Environment variables

Copy the example environment file and adjust as needed:

```sh
cp .env.example .env
```

### Development

Start the Vite dev server:

```sh
npm run dev
```

or with pnpm:

```sh
pnpm dev
```

### Build

```sh
npm run build
```

or with pnpm:

```sh
pnpm build
```

### Lint

```sh
npm run lint
```

or with pnpm:

```sh
pnpm lint
```
